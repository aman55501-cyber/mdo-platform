**Ground rule.** Nothing below is a fact about the real world. Treat every "due" as **[UNVERIFIED]**. The only place a filing row can be created today is the seed file or raw SQL — there is no `POST /api/compliance/filings`; the app can only flip status.

Entity names below are as they appear after the seed's own rename pass (`Ozone Steel Pvt Ltd` → `Ozone Steel & Power Ltd`, `Hotel ANS` → `Hotel ANS International Ltd`).
