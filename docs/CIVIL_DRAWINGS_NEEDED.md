# Civil drawings needed for strength-testing QC (P3)

Source for the structure list: the Vedanta process flow diagram (docs/WASHERY_DRAWINGS_RECEIVED.md). Ask the structural consultant, the washery vendor/designer and the civil contractor.
Only the latest GFC (Good For Construction) revision counts. Ask for every drawing as PDF plus the DWG if available.

## 0. First six items (these start the work)
1. GFC drawing register: the list of every structural/civil drawing issued, with number, title, revision, date. One sheet. This tells us what exists.
2. Washery building: foundation layout plan, footing/pile schedule with sizes and reinforcement, column layout and base-plate/anchor-bolt plan.
3. Feed bunker (500 MT) and hoppers: structural drawings with reinforcement details, wall and base slab sections, liner details.
4. Thickener tank (dia 18 m is annotated on the flow diagram; confirm which item): base slab, wall, central pier/bridge support, launders, with reinforcement.
5. The four infrastructure packages: CC road, CC platform, drainage, weighbridge (see section 2).
6. Geotechnical report with borehole logs and recommended safe bearing capacity. Not a drawing, but without it no foundation can be judged.

## 1. Per structure (from the process flow)
| Structure | Drawings to ask for | What QC checks against them |
|---|---|---|
| Washery building / main structure | Foundation plan, footing schedule, column and beam layout per floor, slab reinforcement, steel framing and connection details, anchor-bolt plan | footing size/depth, rebar, cover, concrete grade, anchor-bolt position |
| Feed bunker 500 MT, hoppers, VF-I/II supports | Bunker/hopper structure with reinforcement; vibrating-feeder support frames; OEM load data | wall thickness, rebar, liner, dynamic-load design |
| Rotary breaker I and II foundations | Equipment foundation drawings with OEM dynamic loads and anchor layout | block size, rebar, anchor-bolt position, grouting |
| Screen house (vibrating screen 500 TPH, flip-flow 150 TPH) | Floor framing plan, screen support and foundation drawings with OEM loads | support steel/RCC, dynamic loading, anchors |
| Crusher house, stack house | Foundation and framing drawings | as above |
| Conveyors BC-1 to BC-9 (800-1400 mm belt) | Gallery plan/elevation, trestle foundation and member schedule, transfer-tower details | trestle footings, member sizes, alignment tolerances |
| Thickener, FRS tank, CLS tank | Tank structural drawings, construction-joint and waterstop details | rebar, cover, joints, leak test result |
| Settling pond | Plan with levels, section, embankment, lining/waterproofing | levels, compaction, lining continuity |
| Chimney, bag filter, ID fan | Chimney foundation and stack drawing, fan/filter foundations | foundation size, anchor bolts, height vs consent |
| Belt press area | Floor/foundation drawing | loads and floor slab |

## 2. Internal infrastructure (live work)
| Package | Drawings to ask for |
|---|---|
| CC road | Alignment plan, longitudinal section, typical cross-sections (width, camber, thickness), pavement design (subgrade, base, PQC grade/thickness), joint layout with dowel/tie-bar details |
| CC platform | General arrangement, slab thickness, reinforcement, joint layout, levels and falls |
| Drainage | Layout plan with invert levels and gradients, typical drain sections, cover/slab details, silt traps, outfall and discharge point |
| Weighbridge | OEM pit and foundation drawing, load-cell layout, approach slabs, pit drainage; Legal Metrology verification certificate when done |

## 3. Records that go with the drawings (the QC needs these as evidence)
Approved mix designs; pour register; cube register with 7- and 28-day results from a NABL lab; mill test certificates for steel and cement; compaction and sand-replacement tests for fills and subgrade; pre-pour checklists; the measurement book and RA bills.
